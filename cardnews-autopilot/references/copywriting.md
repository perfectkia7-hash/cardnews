# 카드뉴스 카피 규칙

이 규칙은 생성 모드(Claude 가 직접 작성)와 자동 모드(API 호출) 양쪽에서 똑같이 쓰인다.

## 두 가지 형식 — 기본은 스토리형

| | 스토리형 (`story`) · **기본** | 다이제스트형 (`news`) |
|---|---|---|
| 한 편에 담는 것 | **사건 하나** | 여러 뉴스 요약 |
| 카드마다 | 헤드라인 + **설명 본문** | 헤드라인만 |
| 쓸 때 | 매주 1~2회, 큰 이슈 | 주간/일간 모아보기 |

**기본은 스토리형이다.** 사람들이 저장하고 공유하는 건 "무슨 일이 일어난 건지 알려주는" 쪽이지, 제목만 늘어놓은 쪽이 아니다. 사용자가 "모아보기", "정리", "주간 뉴스" 를 명시적으로 요청할 때만 다이제스트형으로 간다.

## 스토리형 구성

한 사건을 6~8장으로 푼다. **카드마다 하나의 논점**만 담는다.

```
표지    후킹 — 왜 넘겨봐야 하는지
1장     무슨 일이 일어났나 (핵심 사실 + 숫자)
2장     왜 중요한가 (영향, 당사자 발언)
3장     배경 — 왜 어려웠나 / 지금까지는 어땠나
4장     구체적 사례 (실제 사건, 수치)
5장     남은 질문 / 앞으로
엔딩    저장·팔로우 유도 (자동 생성)
```

순서는 소재에 따라 바꿔도 되지만, **표지 다음에 곧바로 핵심 사실**이 와야 한다. 배경 설명부터 시작하면 넘기지 않는다.

### 본문(`body`) 쓰는 법 — 스토리형의 핵심

- **2~4문장.** 문장마다 `\n` 으로 줄을 나눈다
- **한 문장 30자 이내** (최대 36자). 넘으면 자동 줄바꿈되어 리듬이 깨진다
- 숫자·고유명사·핵심 구절은 `**강조**` 로 감싼다 → 흰색 굵은 글씨로 나온다
- 기사에서 **직접 인용**을 하나쯤 넣으면 신뢰도가 확 오른다

```
"미국 국립허리케인센터 마이크 브레넌 소장은 **'몇 시간만 빨라도 차이가 난다'**고 했습니다.\n대피 조직, 물자 배치, 자원 이동은 전부 시간 싸움입니다.\n판단이 늦으면 대가가 큽니다."
```

### 사진은 있는 것만

- 사진이 있는 카드는 사진 + 글, 없는 카드는 **글만 있는 카드**로 자동 전환된다
- 사진 카드와 텍스트 카드가 번갈아 나오는 게 오히려 자연스럽다. **억지로 다 채우지 않는다**
- 같은 사진을 두 장 이상에 쓰지 않는다. 표지와 본문에 같은 사진이 들어가면 티가 난다

## 헤드라인은 두 줄로 — 1줄 후킹, 2줄 사실

실제로 잘 되는 뉴스 카드뉴스 계정들이 전부 쓰는 문법이다. 첫 줄로 궁금하게 만들고, 둘째 줄에서 사실을 확인시킨다.

```
건담이 현실이 됐다
유니트리 유인 로봇 GD01 공개

푸틴의 킬러 로봇 등장
인간 없이 5초마다 자동 발사

중국의 진짜 병목은
반도체가 아니었다
```

두 줄의 **길이를 비슷하게** 맞춘다. 한 줄만 길면 조판이 흐트러진다.

```
나쁨:  "AI가 만든 바이러스 16종,\n자연에 없던 것들"   ← 1줄이 너무 긺
좋음:  "AI가 바이러스를 만들었다\n자연에 없던 16종"
```

한 문장을 억지로 두 줄로 자르지 않는다. **두 줄이 각각 독립적으로 읽혀야 한다.**

## 사진이 주인공이다

기본 템플릿(`news`)에서는 **사진이 카드의 대부분을 차지하고, 화면에 나가는 글자는 헤드라인 두 줄뿐이다.**

- 카드마다 `articleIndex`(자동 모드) 또는 `image`(생성 모드)로 기사 사진을 연결한다
- **사진이 없는 기사는 되도록 고르지 않는다.** 사진 없는 카드가 섞이면 그 카드만 자동 생성 티가 확 난다
- 중요도가 비슷하면 사진 있는 쪽을 고른다
- `body` 는 카드에 안 찍히고 **캡션 재료로 쓰인다.** 그래도 성실하게 쓴다

사진이 정 없으면 그 소식은 빼거나, 사진 없이도 어울리는 타이포 템플릿(`minimal`, `darktech` 등)으로 바꾼다.

## 글자 수 — 어기면 이미지가 깨진다

렌더러가 넘치는 글자를 자동으로 줄여주긴 하지만, 그러면 카드마다 글씨 크기가 달라져 조잡해 보인다. **처음부터 아래 범위 안에서 쓴다.**

| 항목 | 권장 | 최대 | 비고 |
|---|---|---|---|
| 표지 `title` | 18~26자 | 30자 | `\n` 으로 2줄. 한 줄 15자 넘기지 않기 |
| 표지 `subtitle` | 15~22자 | 28자 | 1줄. 줄바꿈 없이 |
| 카드 `headline` | 16~26자 | 32자 | `\n` 으로 2줄. **한 줄 16자 넘기지 않기** |
| 카드 `body` (story) | 90~150자 | 200자 | **문장당 30자**, `\n` 으로 줄 나눔 |
| 카드 `body` (news) | 70~120자 | 140자 | 카드엔 안 보이고 캡션 재료로 쓰임 |
| `source` | 매체명만 | 20자 | "Ars Technica" 처럼 |
| `caption` | 150~350자 | 2,200자 | 인스타 본문 |
| `hashtags` | 5~8개 | 30개 | `#` 포함 |

한글은 글자 폭이 넓다. **영문 기준으로 세지 말 것.**

### 줄바꿈은 의미 단위로

`\n` 을 넣을 땐 어절 중간이 아니라 의미가 끊기는 곳에 넣는다.

```
좋음:  "AI가 설계한 바이러스,\n실제로 작동했다"
나쁨:  "AI가 설계한\n바이러스, 실제로 작동했다"      ← 줄 길이가 안 맞음
나쁨:  "AI가 설계한 바이러스, 실제로\n작동했다"      ← 첫 줄이 너무 긺
```

## 구조

```
표지    후킹 — 왜 넘겨봐야 하는지
본문 1  가장 센 소식 (제일 중요한 걸 앞에)
본문 2~4  나머지, 중요도 순
엔딩    렌더러가 자동 생성 (저장·팔로우 유도)
```

본문은 **3~5장**이 적당하다. 6장 넘어가면 이탈한다.

## 쓰는 법

**표지는 질문이나 반전으로 연다.** 요약문이 아니다.

```
좋음:  "중국의 진짜 병목은\n반도체가 아니었다"
나쁨:  "이번 주 AI 업계 주요 뉴스 정리"
```

**본문은 결론부터.** 배경 설명으로 시작하지 않는다.

```
좋음:  "중국 AI 업계가 부딪힌 벽은 칩이 아니라 데이터입니다. 학습에 쓸
       중국어 텍스트가 바닥나고 있습니다."
나쁨:  "최근 중국의 AI 산업이 빠르게 성장하고 있는 가운데, 여러 가지
       어려움에 직면하고 있다는 소식이 전해졌습니다."
```

**숫자를 살린다.** "많은 바이러스" 보다 "바이러스 16종"이 훨씬 강하다. 단, **원문에 있는 숫자만** 쓴다.

**문체는 '~습니다'로 통일한다.** 개조식(~함, ~임)과 섞지 않는다.

**여러 기사를 하나의 흐름으로 엮는다.** 목록 나열이 아니라, 표지에서 던진 주제를 본문이 이어받는 구성으로 만든다.

## 캡션

첫 줄이 미리보기에 노출된다. 여기에 가장 흥미로운 한 문장을 둔다.

```
AI가 자연에 없던 바이러스를 만들어냈습니다. 성과라기엔 서늘한 소식이죠.

이번 주 AI 업계에서 가장 중요했던 4가지를 정리했습니다.
저장해두고 천천히 보세요.
```

해시태그는 캡션 본문과 줄을 띄워 마지막에 붙인다. 대형 태그(#AI)와 중소형 태그(#반도체뉴스)를 섞는다.

## 사진 사용에 관한 주의

카드에 들어가는 사진은 기사 페이지의 대표 이미지(og:image)를 그대로 가져온 것이다. 뉴스 요약 계정들이 관행적으로 쓰는 방식이지만, **저작권이 매체나 사진가에게 있다는 점은 그대로다.**

위험을 줄이려면:

- 카드와 캡션에 **매체명을 반드시 밝힌다** (템플릿이 캡션에 출처를 넣는다)
- 사진을 자르거나 덧칠해 원본인 척하지 않는다
- 인물 사진, 사건·사고 현장 사진은 특히 조심한다
- 매체에서 내려달라는 요청이 오면 바로 내린다

계정을 크게 키울 계획이라면 무료 스톡(Unsplash, Pexels)이나 직접 만든 이미지로 바꾸는 걸 고려한다.

## 절대 하지 않을 것

- **원문에 없는 사실·숫자·발언·날짜를 만들지 않는다.** 카드뉴스는 그대로 공개 발행되고, 오보의 책임은 계정 주인에게 간다. 애매하면 그 카드를 뺀다.
- 기사 문장을 그대로 길게 옮기지 않는다. 요약하고 매체명을 밝힌다.
- 확인되지 않은 추측을 단정형으로 쓰지 않는다. ("~로 보입니다", "~라고 전했습니다" 를 쓴다)
- 특정 종목·코인의 매수/매도를 권하지 않는다.
- 자극적인 낚시 제목으로 내용과 다른 기대를 만들지 않는다.

## 사실 확인 체크리스트

원고를 넘기기 전 스스로 확인한다.

- [ ] 모든 숫자가 수집한 기사에 실제로 있는가
- [ ] 인용한 발언의 화자가 맞는가
- [ ] 카드마다 `source` 가 그 내용의 실제 출처인가
- [ ] 글자 수가 위 표 범위 안인가
- [ ] `\n` 위치가 어절을 쪼개지 않는가
