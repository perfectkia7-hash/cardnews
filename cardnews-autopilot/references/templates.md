# 카드 디자인 템플릿

전부 1080×1350 (4:5) 로 나온다. 인스타 피드에서 세로 공간을 가장 크게 쓰는 비율이다.

## 7종

### `story` — 사진 + 헤드라인 + 설명 · **기본값**
사건 하나를 여러 장으로 풀어내는 형식. 사진이 위, 헤드라인과 설명이 아래에 들어간다. **사진이 없는 카드는 글만 있는 카드로 자동 전환**되므로, 사진 카드와 텍스트 카드가 번갈아 나오는 자연스러운 구성이 된다.

**어울리는 것** 큰 이슈 하나를 제대로 설명할 때. 저장·공유가 가장 많이 나오는 형식
**본문** 카드마다 2~4문장이 들어간다. `**강조**` 로 감싼 부분은 흰색 굵은 글씨가 된다
**사진** 있으면 좋지만 전부 채울 필요 없다. 1~3장이면 충분하다

### `news` — 사진 + 하단 자막 · 모아보기용
기사 사진이 화면을 채우고, 하단 검은 밴드에 작은 키커(`계정명 | 최신 AI 뉴스`)와 굵은 흰 헤드라인 두 줄이 들어간다. 실제로 잘 되는 뉴스 카드뉴스 계정들이 쓰는 문법 그대로다.

기사 사진이 화면을 채우고 하단 검은 밴드에 헤드라인 두 줄만 들어간다. **설명 본문은 카드에 안 나온다.** 여러 뉴스를 훑는 주간·일간 모아보기에 맞다.

**어울리는 것** "이번 주 AI 뉴스 5" 같은 다이제스트
**필요한 것** 기사 사진. `--preset` 이나 `--feeds` 로 실제 매체 RSS 를 써야 붙는다 (구글 뉴스 단독으로는 사진이 안 나온다)

> 아래 5종은 사진 없이 타이포그래피만으로 가는 스타일이다. 사진을 못 구하는 주제이거나, 텍스트 정보 자체가 콘텐츠일 때 쓴다.

### `minimal` — 밝고 조용한 정보 전달형
아이보리 배경에 검정 산세리프. 여백이 넓고 상단에 얇은 강조선이 하나 들어간다.
**어울리는 분야** 시사, 경제, 커리어, 자기계발, B2B
**피할 곳** 화려한 비주얼로 승부하는 계정

### `breaking` — 고대비 강조형
블랙 배경 + 레드 배지. 헤드라인이 굵고 크며, 본문 카드 왼쪽에 세로 바가 붙는다.
**어울리는 분야** 속보, 이슈, 사건사고, 스포츠, 정치
**피할 곳** 잔잔한 톤의 브랜드 계정 — 매일 쓰면 피로해진다

### `magazine` — 에디토리얼 감성
크림색 배경에 명조 제목. 상단에 얇은 구분선과 큰 숫자가 들어간다.
**어울리는 분야** 라이프스타일, 문화, 인터뷰, 책, 여행, 뷰티
**피할 곳** 숫자·데이터 중심 콘텐츠

### `darktech` — 다크 + 네온
딥네이비 그라디언트, 배경 그리드, 모노스페이스 라벨. 표지 제목에 그라디언트가 들어간다.
**어울리는 분야** AI, IT, 개발, 코인, 반도체, 스타트업
**피할 곳** 따뜻한 감성이 필요한 주제

### `board` — 패널 정리형
흰 배경 위에 둥근 패널. 표지는 강조색으로 꽉 채우고 본문은 회색 패널에 담긴다. 번호가 크게 붙는다.
**어울리는 분야** 꿀팁, 정보 정리, 교육, 하우투, 리스트형 콘텐츠
**피할 곳** 무거운 시사 이슈

## 고르는 기준

주제만 보지 말고 **계정 전체의 톤**을 본다. 매일 올리는 계정이라면 한 템플릿을 계속 쓰는 게 브랜드가 쌓인다. 이슈가 클 때만 `breaking` 으로 바꾸는 식이 좋다.

## 브랜딩 바꾸기

렌더 시 옵션으로 넘긴다.

```bash
node scripts/render.mjs --draft out/draft.json --template darktech --out out/cards \
  --handle "@my_news" --accent "#FF6B35" --label "데일리 브리핑"
```

| 옵션 | 하는 일 |
|---|---|
| `--handle` | 계정 표시. `news` 에선 키커 앞부분 |
| `--accent` | 강조색 |
| `--label` | `news` 는 키커 뒷부분(`최신 AI 뉴스`), 나머지는 표지 배지 문구 |
| `--no-outro` | 마지막 팔로우 유도 카드를 빼기 |
| `--no-images` | 사진을 받지 않고 렌더 (오프라인 테스트용) |

## 디자인 직접 고치기

각 템플릿은 `templates/*.html` 파일 하나로 끝난다. CSS 가 그 안에 다 들어 있으니 색·폰트·여백을 바로 고치면 된다. 구조를 다루는 코드는 `templates/_engine.js` 한 곳에 모여 있어서 건드릴 일이 거의 없다.

새 템플릿을 만들려면 기존 파일을 복사해 이름만 바꾸면 바로 `--template 새이름` 으로 쓸 수 있다.

**주의** `.card` 는 반드시 1080×1350 을 유지해야 한다. `.fit` 의 `overflow: hidden` 도 지워선 안 된다 — 글자 자동 축소가 이 둘에 기대고 있다.

## 폰트

기본은 Pretendard(본문)와 나눔명조(magazine 제목)를 CDN 에서 받는다. 인터넷이 끊긴 환경에서는 시스템 폰트로 대체되므로 줄바꿈 위치가 조금 달라질 수 있다.

다른 폰트를 쓰려면 템플릿 HTML 의 `<link>` 와 `font-family` 를 바꾸면 된다.
