# 카드뉴스 오토파일럿 — 시작하기

구매해 주셔서 감사합니다. **이 파일 하나만 따라오시면 됩니다.**

> 이 문서가 시작점입니다. 다른 파일은 지금 열지 않으셔도 됩니다.

두 가지를 할 수 있습니다. 순서대로 하세요 — 1번이 되면 2번은 설정만 남습니다.

| | 하는 일 | 걸리는 시간 | 준비물 |
|---|---|---|---|
| **① 만들기** | 주제 하나 → 카드뉴스 이미지 완성 | **2분** | 없음 |
| **② 자동 굴리기** | 매일 정해진 시각에 텔레그램으로 초안 → 버튼 한 번에 인스타 발행 | 30~60분 | 텔레그램·인스타·GitHub |

---

## 먼저 이 두 가지가 필요합니다

### 1. Claude Code

이건 **Claude Code 스킬**입니다. Claude Code 안에서 동작합니다.

- 없으시면: <https://claude.com/claude-code> 에서 설치
- Claude 구독(Pro/Max 등)이 있으면 추가 요금이 없습니다

### 2. Node.js 20 이상

- 없으시면: <https://nodejs.org> 에서 LTS 버전 설치
- 확인: 터미널에 `node --version` → `v20` 이상이면 OK

## 설치 — 폴더를 어디에 둘지가 중요합니다

**①번만 쓰실 거면** 아무 프로젝트 폴더에나 두셔도 됩니다.

```
<아무 폴더>/.claude/skills/cardnews-autopilot/
```

**②번(매일 자동)까지 쓰실 거면 반드시 GitHub 레포 안에 두세요.**

```
<클론한 레포>/.claude/skills/cardnews-autopilot/
```

> 자동 모드는 GitHub Actions 가 그 레포를 내려받아 실행합니다. 레포 밖에 있으면 GitHub 이 파일을 볼 수 없어서 아무것도 돌지 않습니다. **나중에 옮기려면 설정을 다시 해야 하니 처음부터 레포 안에 두시는 걸 권합니다.**

폴더를 옮겼으면 그 안에서 한 번만:

```bash
npm install
```

15초쯤 걸립니다. (크롬 300MB 를 받지 않습니다 — 이미 깔린 브라우저를 씁니다.)

## ① 카드뉴스 만들기 — 2분

Claude Code 를 켜고 그냥 말하면 됩니다.

```
카드뉴스 만들어줘. 주제는 AI 최신 뉴스로.
```

Claude 가 뉴스를 모으고, 카피를 쓰고, 1080×1350 카드 이미지를 만들어 줍니다. 결과는 `out/cards/` 에 JPEG 로 나옵니다. 인스타에 직접 올리시면 됩니다.

이렇게도 말할 수 있습니다.

```
카드 7장으로 만들어줘
디자인 좀 더 밝은 걸로 바꿔줘
두 번째 카드 문구가 어색해, 다시 써줘
코인 뉴스로 만들어줘
```

**여기까지는 API 키도, 설정도 필요 없습니다.** Claude Code 안의 Claude 가 직접 카피를 씁니다.

## ② 매일 자동으로 굴리기 — 30~60분

한 번만 설정하면, 이후로는 **하루 세 번 텔레그램을 보고 버튼만 누르면** 됩니다.

```
매일 아침 8시에 텔레그램으로 초안 받고 싶어. 자동 모드 세팅해줘
```

이렇게 말하면 Claude 가 순서대로 안내하고, **설정 파일과 스케줄은 Claude 가 직접 만들어 줍니다.** 터미널에 앉아 하나씩 답하실 필요 없습니다.

준비물은 세 가지입니다. 전부 무료입니다.

**안내 도우미를 쓰세요.** 네 가지를 한 단계씩 붙잡고 갑니다.

```bash
node scripts/onboard.mjs
```

필요한 사이트를 순서에 맞춰 열어 주고, 어느 화면에서 무슨 버튼을 누르는지 알려주고, **받은 값이 맞는지 그 자리에서 확인**해 줍니다. 채팅 ID 와 인스타 계정 ID 는 자동으로 찾아 채웁니다. 중간에 그만둬도 다시 실행하면 멈춘 곳부터 이어집니다.

아래는 도우미가 안내하는 내용을 문서로 정리한 것입니다.

> **받은 값은 두 군데에 넣습니다.** 헷갈리기 쉬운 부분이라 먼저 짚고 갑니다.
>
> | 어디에 | 무엇을 위해 |
> |---|---|
> | 폴더 안의 **`.env`** 파일 | 내 PC 에서 시험해 볼 때 |
> | GitHub **Secrets** | 실제 매일 자동 실행 |
>
> `.env` 는 `.env.example` 을 복사해서 이름만 바꾸면 됩니다. 어떤 값이 필요한지 그 안에 다 적혀 있습니다. **`.env` 는 커밋되지 않으니 안심하세요.**

### 준비물 1 — 텔레그램 봇 (5분)

텔레그램에서 `@BotFather` 를 찾아 `/newbot` → 이름 정하기 → **토큰**을 받습니다.

토큰을 `.env` 에 넣고 아래를 실행하면 **채팅 ID 는 자동으로 채워집니다.**

```bash
node scripts/telegram-setup.mjs
```

### 준비물 2 — 인스타그램 (20~40분, 여기가 제일 오래 걸립니다)

- 인스타 계정을 **프로 계정(비즈니스)** 으로 전환
- <https://developers.facebook.com> 에서 앱 만들기 → 액세스 토큰 발급

액세스 토큰을 `.env` 에 넣고 아래를 실행하면 **계정 ID 는 자동으로 찾아 채웁니다.**

```bash
node scripts/instagram-setup.mjs
```

화면 순서는 `references/setup-automation.md` 에 적어 뒀습니다. Claude 에게 "인스타 연동 안내해줘" 라고 하면 그걸 읽고 짚어 줍니다. **막힌 화면을 캡처해서 보여주시면 더 정확합니다.**

> **심사는 필요 없습니다.** 본인 계정에만 올리는 구조라 개발 모드로 동작합니다.
>
> 다만 개발 모드에서는 **앱에 역할로 등록된 계정만** 인증됩니다. 내 계정이라도 등록해야 합니다 — 앱 대시보드 → **앱 역할** → **사용자 추가** → **Instagram 테스터** 로 본인 계정을 초대하고, **인스타 앱에서 설정 → 앱 및 웹사이트 → 테스터 초대 → 수락**까지 해야 합니다. 수락을 빼먹어 막히는 경우가 가장 많습니다.

### 준비물 3 — GitHub 공개 레포 (5분)

이미지 저장소와 스케줄러를 동시에 해결합니다. **공개(Public)로 만드세요** — 인스타가 공개된 이미지 주소만 받고, 공개 레포는 실행 시간이 무제한이라 비용이 0원입니다.

### 마지막 — Secrets 등록

받은 값들을 GitHub 레포의 **Settings → Secrets and variables → Actions** 에 넣습니다.

| 이름 | 값 |
|---|---|
| `TELEGRAM_BOT_TOKEN` | BotFather 토큰 |
| `TELEGRAM_CHAT_ID` | 본인 채팅 ID (스크립트가 찾아줍니다) |
| `IG_USER_ID` | 인스타 계정 ID (스크립트가 찾아줍니다) |
| `IG_ACCESS_TOKEN` | Meta 앱 액세스 토큰 |
| `CLAUDE_CODE_OAUTH_TOKEN` | 터미널에서 `claude setup-token` 실행 후 나온 값 |

> `GITHUB_TOKEN` 은 **등록하지 마세요.** GitHub 이 자동으로 넣어줍니다.

마지막 줄이 중요합니다. **Claude 구독이 있으면 `claude setup-token` 으로 만든 토큰을 쓰세요. 구독 사용량으로 돌아가서 API 요금이 따로 나가지 않습니다.** 구독이 없을 때만 `ANTHROPIC_API_KEY` 를 쓰시면 되고, 그것도 하루 한 편이면 월 1달러 안쪽입니다.

전부 넣었으면 설정 파일과 스킬 폴더를 커밋해서 push 하고, Actions 탭 → `cardnews` → **Run workflow** 로 한 번 시험해 보세요.

## 매일 이렇게 굴러갑니다

```
정해진 시각  →  뉴스 수집 → 카피 → 카드 렌더 → 텔레그램으로 미리보기
                                                        ↓
                          [ ✅ 발행 ]  [ 🗑 취소 ]  ← 여기서 버튼만 누르시면 됩니다
                                ↓
                          인스타그램에 캐러셀 발행 완료
```

- **버튼은 24시간 살아 있습니다.** 바로 못 누르셔도 나중에 누르면 그대로 올라갑니다.
- 취소하면 발행하지 않고, 그 소재는 다시 나오지 않습니다.
- 발행이 끝나면 **음악 붙이는 방법**을 텔레그램으로 알려드립니다 (인스타 앱에서 15초. 음악은 API 로는 붙일 수 없어 이 단계만 손이 갑니다).

## 막히면

**제일 먼저 이걸 돌려 보세요.** 뭐가 빠졌는지 짚어 줍니다.

```bash
node scripts/doctor.mjs
```

Claude 에게 그 결과를 그대로 보여주면서 "이거 어떻게 고쳐?" 라고 하셔도 됩니다.

증상별 해결은 `references/troubleshooting.md` 에 정리돼 있습니다.

---

## 알아두시면 좋은 것

- **인스타 액세스 토큰은 60일마다 갱신해야 합니다.** 만료 10일 전에 텔레그램으로 알려드립니다. `node scripts/refresh-token.mjs` 를 돌려 나온 값을 Secrets 에 덮어쓰면 끝입니다.
- **사진은 기사 대표 이미지를 씁니다.** 뉴스 요약 계정들의 일반적인 방식이지만 저작권은 각 매체에 있습니다. 상업적으로 크게 쓰실 계획이면 이 점을 감안하세요.
- **카드에 들어간 내용은 그대로 공개 발행됩니다.** 발행 전에 텔레그램 미리보기에서 사실관계를 한 번 봐 주세요.

## 파일 안내

```
README.md        ← 지금 보고 계신 파일
SKILL.md         Claude 가 읽는 지침 (직접 고치실 필요 없습니다)
config/          설정. config.json 을 고치면 다음 실행부터 반영됩니다
templates/       카드 디자인 7종. CSS 라 직접 고치셔도 됩니다
references/      카피 규칙 · 디자인 가이드 · 세팅 순서 · 문제해결
scripts/         실제 동작 코드
```

가장 자주 고치게 될 파일은 `config/config.json` 입니다. 발행 시각, 분야, 카드 장수, 계정 핸들이 전부 여기 있습니다. 고치고 push 하면 다음 실행부터 적용됩니다.
