1

준비물 확인

Claude Code

이건 Claude Code 스킬입니다. 엑셀 파일이 엑셀에서 열리듯, Claude Code 안에서 동작합니다.

없으시면 claude.com/claude-code 에서 설치하세요. Claude 구독(Pro/Max)이 있으면 추가 요금이 없습니다.

Node.js 20 이상

터미널(윈도우는 PowerShell, 맥은 터미널)에 입력해 보세요.

node --version

v20 이상이면 됩니다. 없다고 나오면 nodejs.org 에서 LTS 를 설치하세요.

2

폴더 위치 — 여기가 제일 중요합니다

압축을 푼 cardnews-autopilot 폴더를 .claude/skills/ 안에 넣습니다.

<작업 폴더>/
  .claude/
    skills/
      cardnews-autopilot/   ← 이 폴더

매일 자동 발행까지 쓰실 거면 GitHub 레포를 클론한 폴더 안에 두세요.

자동 발행은 GitHub 이 그 폴더를 내려받아 실행하는 구조입니다. 레포 밖에 있으면 아무것도 돌지 않습니다. 나중에 옮기면 설정을 처음부터 다시 해야 합니다.

옮기신 뒤 폴더 안에서 한 번만 실행하세요. 15초쯤 걸립니다.

npm install

크롬 300MB 를 받지 않습니다. 이미 깔린 브라우저를 씁니다.

Claude Code 를 껐다 켜세요. 그래야 스킬이 인식됩니다.

3

첫 카드뉴스 — 2분

설정도 API 키도 필요 없습니다. Claude Code 에서 그냥 말하세요.

카드뉴스 만들어줘. 주제는 AI 최신 뉴스로.

뉴스를 모으고, 카피를 쓰고, 1080×1350 카드 이미지를 만들어 줍니다. 결과는 out/cards/ 에 JPEG 로 나옵니다.

이렇게도 말할 수 있습니다.

  • 카드 7장으로 만들어줘
  • 디자인 더 밝은 걸로 바꿔줘
  • 두 번째 카드 문구가 어색해, 다시 써줘
  • 코인 뉴스로 만들어줘

여기까지 마음에 드셨다면 자동 발행으로 넘어가세요. 아니라면 문구·디자인을 먼저 손보셔도 됩니다. 자동 발행은 언제든 나중에 켤 수 있습니다.

4

매일 자동 발행 — 30~60분

한 번만 설정하면, 이후로는 텔레그램을 보고 버튼만 누르면 됩니다.

매일 아침 8시에 텔레그램으로 초안 받고 싶어. 자동 모드 세팅해줘

설정 파일과 예약 스케줄은 Claude 가 직접 만들어 줍니다. 터미널에 앉아 하나씩 답하실 필요 없습니다.

직접 발급하셔야 하는 값 4개

이것만 구매자님 손이 필요합니다. 비밀번호와 토큰은 Claude 가 대신 만들지 않습니다 — 계정 탈취와 구분되지 않는 행동이라서요.

대신 안내 도우미를 넣어 뒀습니다. 터미널에서 이 한 줄을 실행하세요.

node scripts/onboard.mjs

도우미가 하는 일

  • 필요한 사이트를 순서에 맞춰 열어 줍니다 (윈도우·맥·리눅스 알아서)
  • 어느 화면에서 무슨 버튼을 누르는지 화면 순서대로 알려줍니다
  • 받은 값을 그 자리에서 검증합니다. 틀리면 왜 틀렸는지 말해 줍니다
  • 채팅 ID·인스타 계정 ID는 자동으로 찾아 채웁니다
  • 중간에 그만두셔도 됩니다. 다시 실행하면 멈춘 곳부터 이어서 갑니다
무엇어디서시간
텔레그램 봇 토큰텔레그램 @BotFather5분
Claude 토큰터미널 claude setup-token2분
GitHub 공개 레포github.com5분
인스타 액세스 토큰developers.facebook.com20~40분 ← 제일 깁니다

그래도 막히시면 그 화면을 캡처해서 Claude 에게 보여주세요. 그게 제일 빠릅니다.

마지막 — GitHub Secrets 에 넣기

도우미가 끝나면 등록할 목록과 페이지를 열어 줍니다. 레포의 Settings → Secrets and variables → Actions 화면인데, 붙여넣기만은 직접 하셔야 합니다.

GITHUB_TOKEN 은 등록하지 마세요. GitHub 이 자동으로 넣어줍니다. 직접 등록하면 충돌합니다.

전부 넣으셨으면 Actions 탭 → cardnews → Run workflow 로 한 번 시험 실행해 보세요.

5

매일 이렇게 굴러갑니다

정해진 시각 → 뉴스 수집 → 카피 → 카드 렌더 → 텔레그램 미리보기
                                            ↓
                        [ ✅ 발행 ]   [ 🗑 취소 ]
                                ↓
                        인스타그램 캐러셀 발행 완료
  • 버튼은 24시간 살아 있습니다. 바로 못 누르셔도 나중에 누르면 그대로 올라갑니다.
  • 취소하면 발행하지 않고, 그 소재는 다시 나오지 않습니다.
  • 발행 후 음악 붙이는 방법을 텔레그램으로 알려드립니다 (앱에서 15초).

막히면

제일 먼저 이것부터 돌려보세요. 무엇이 빠졌는지 짚어 줍니다.

node scripts/doctor.mjs

결과를 그대로 Claude 에게 보여주며 "이거 어떻게 고쳐?" 라고 하셔도 됩니다.

증상별 해결은 references/troubleshooting.md 에 정리돼 있습니다.

알아두시면 좋은 것

  • 인스타 토큰은 60일마다 갱신해야 합니다. 만료 10일 전에 텔레그램으로 알려드립니다. node scripts/refresh-token.mjs 로 새 값을 받아 Secrets 에 덮어쓰면 끝입니다.
  • 사진은 기사 대표 이미지를 씁니다. 뉴스 요약 계정들의 일반적인 방식이지만 저작권은 각 매체에 있습니다. 상업적으로 크게 쓰실 계획이면 감안하세요.
  • 발행 전에 미리보기를 확인해 주세요. 카드 내용은 그대로 공개 발행되고, 사실관계의 책임은 계정 주인에게 갑니다.
  • 자동 발행(autoPublish)은 켜지 마세요. 발행 버튼을 사람이 누르는 단계가 계정을 지켜줍니다.
